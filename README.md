# Cloud-Based Data Analytics System 

## Project Overview
This is a cloud-based service developed for searching, sorting, and classifying a large collection of documents.

## Key Features
* **Cloud Storage**: Documents are stored and retrieved from **Supabase**.
* **Smart Search**: Highlighting keywords inside PDF and Word documents.
* **Auto-Classification**: Documents are classified using a predefined tree.
* **Analytics Dashboard**: Real-time statistics on file size, count, and processing time.

## How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Run the app: `streamlit run search_dashboard.py`
